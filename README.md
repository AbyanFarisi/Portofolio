# Portofolio Abyan Farisi Syahrial

Website portofolio interaktif dan responsif untuk menampilkan profil, keahlian teknis, dan studi kasus proyek sebagai **Fullstack Developer & System Analyst**.

🌐 **Live Demo:** [https://abyanfarisi.github.io/Portofolio/](https://abyanfarisi.github.io/Portofolio/)

---

## 🚀 Fitur Utama

- **Desain Modern & Responsif**: Menggunakan Tailwind CSS dan tipografi Google Fonts (*Plus Jakarta Sans*, *Inter*, dan *JetBrains Mono*) yang dioptimalkan untuk perangkat mobile, tablet, dan desktop.
- **Dark & Light Mode**: Toggle tema gelap dan terang dengan deteksi preferensi sistem dan penyimpanan di `localStorage`.
- **Dukungan Multi-Bahasa (ID / EN)**: Pengalihan bahasa instan antara Bahasa Indonesia dan Bahasa Inggris tanpa reload halaman.
- **Filter Kategori Proyek**: Navigasi filter interaktif untuk memilah proyek berdasarkan *Web Dev*, *System & ERP*, dan *AutoML & AI*.
- **Interactive System & Pipeline Explorer**: Penjelajah langsung 12 modul operasional Zalio ERP dan 12 tahap alur kerja AutoML Pipeline lengkap dengan mock browser URL dan sorotan teknis.
- **Modal Lightbox Galeri Resolusi Tinggi**: Pratinjau screenshot detail resolusi tinggi dengan thumbnail auto-scroll, navigasi sentuh/keyboard, dan mode layar penuh (*expand view*).
- **Akses Langsung Unduh CV**: Tombol unduh CV format PDF (`assets/cv_abyan_webdev.pdf`) dan DOCX.
- **Print Friendly**: Dilengkapi styling `@media print` untuk mencetak atau menyimpan halaman ke format dokumen bersih.

---

## 🛠️ Tech Stack & Toolkit

- **Frontend**: HTML5, CSS3, Tailwind CSS (CDN), JavaScript (ES6+)
- **Backend & Database Experience**: PHP, Laravel, MySQL, RESTful API
- **System Analysis**: UML, Flowchart, Database Normalization, Faspay Payment Gateway Integration, UAT Scenarios
- **Data & AI**: Python, Automated Machine Learning (AutoML), Scikit-Learn, LightGBM, Data Pipelines

---

## 📂 Proyek Unggulan

1. **AFC Indonesia**: Website E-Commerce & Katalog Produk Statis (Laravel & Tailwind CSS).
2. **Jatimelati Bulog Tiga**: Sistem Inventaris Perumahan Terintegrasi & Faspay Payment Gateway.
3. **Zalio ERP Dashboard Suite**: Enterprise Resource Planning Dashboard berbasis microservices (Go, Python FastAPI, Next.js, PostgreSQL) dengan 12 modul operasional (POS Kasir, Sales Flow, Pengadaan PO, Katalog Produk, Arus Kas, Multi-Gudang, COA Akuntansi, Multi-Cabang, Audit Trail, dan CRM).
4. **AutoML Platform & Predictive Pipeline**: End-to-End Automated Machine Learning Pipeline untuk data tabular berbasis metodologi CRISP-DM (Data Ingestion Polars/DuckDB, Profiling EDA, Integritas Data & Leakage Guard, Turnamen Multi-Model LightGBM/XGBoost, Diagnostik Evaluasi ROC-AUC, What-If Inference Simulator, Continuous MLOps Drift Monitor, dan AI Copilot Gemini).
